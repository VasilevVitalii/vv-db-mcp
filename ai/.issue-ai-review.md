## Итог

Постановка хорошо разделяет MCP, оркестрацию и доступ к БД, но **пока не готова к реализации без уточнений**. Основные блокеры: неверная гарантия атомарности, обработка неоднозначного commit, прерывание SQL по лимиту строк, неполная защита секретов и неподтверждённый событийный контракт пакета.

Ниже:
- **Критично** — риск утраты данных, утечки или неверного подтверждения записи.
- **Существенно** — расхождение контрактов или препятствие совместимой реализации.

**Граница проверки:** README и исходники `vv-db-connection` не приложены. Поэтому утверждения о конкретных сигнатурах и событиях пакета нельзя считать проверенными; такие места отмечены как требующие подтверждения, а не как доказанные ошибки. Решение хранить секреты в отдельном файле `key=value` не оспаривается.

## 5. Ошибки и неточности механик/API

### 5.1. Подтверждаемые ошибки SQL и каталогов

| Ссылки | Конкретика |
|---|---|
| `.issue-tech-ai.md:539,837,846` | **Firebird 3.0 уже поддерживает identity columns.** Обоснование исключения identity фактически неверно. Исключить признак можно как решение scope, но не по указанной причине. |
| `.issue-tech-ai.md:430–432` | PostgreSQL выполняет несколько операторов одного simple-query сообщения в одной неявной транзакции, если явное управление транзакциями не меняет это поведение. Поэтому «каждый оператор автокоммитится» и «ранее выполненные остаются применёнными» не являются универсальными правилами батча. |
| `.issue-tech-ai.md:428` | Для MSSQL нет общего соответствия «один оператор — один набор». Один оператор `EXEC` может вернуть несколько наборов; DDL не возвращает табличный набор; сообщения о количестве строк — отдельная механика. |
| `.issue-tech-ai.md:638,863` | PostgreSQL `pg_get_viewdef` возвращает запрос представления, **не полный `CREATE VIEW`**. Для `definitionKind: full` необходимо собрать заголовок. Oracle views отсутствуют в `ALL_SOURCE`; одного префикса к этому источнику для всех типов объектов недостаточно. |
| `.issue-tech-ai.md:638,863` | `sys.sql_modules.definition` содержит сохранённый текст модуля, который может начинаться с `ALTER` или `CREATE OR ALTER`. Гарантия именно `CREATE ...` требует дополнительной обработки. |
| `.issue-tech-ai.md:208` | Oracle хранит quoted-идентификаторы в заданном регистре, а не обязательно в верхнем. Формулировка «Oracle — верхний регистр» неверна без оговорки о некавыченных именах. |
| `.issue-tech-ai.md:526,856` | Универсальное «length в символах» нельзя получить простой нормализацией длины каталога: у MSSQL длина часто в байтах, у Oracle есть BYTE/CHAR semantics. Нужны правила, иначе одинаковое поле будет иметь разный смысл. |
| `.issue-tech-ai.md:603,861` | PostgreSQL имеет `TRUNCATE`-триггеры, Oracle — compound triggers с несколькими timing points. Текущие `events` и скалярный `timing` не представляют их без потерь; исключения не оговорены. |
| `.issue-tech-ai.md:872–874` | Oracle `NUMBER` допускает отрицательный scale, который таблицей явно не классифицирован. Firebird `INT128` — целочисленный тип; безусловное отнесение к decimal смешивает SQL-тип и внутреннее представление NUMERIC/DECIMAL. |
